# Zapret Manager

Отдельное GUI-приложение для Windows, управляющее полной сборкой Zapret из папки рядом с ним. `ZapretManager.exe` — x64 GUI-лаунчер со встроенным PowerShell-интерфейсом: он извлекает скрипт во временную папку и запускает его с правами администратора. Отдельно копировать `ZapretManager.ps1` для работы EXE не требуется.

## Запуск

1. Распакуйте полную сборку Zapret. Папка `app` должна находиться в корне рядом с `bin`, `lists`, `utils`, `general*.bat` и `service.bat`.
2. Запустите **`app\ZapretManager.exe`** и подтвердите запрос UAC.
3. Выберите стратегию и нажмите **«Запустить»**. Для завершения используйте **«Остановить»**.

`app\Start-ZapretManager.bat` — альтернативный запуск исходного `ZapretManager.ps1`, если вы хотите запускать или отлаживать скрипт напрямую.

Требуются Windows 10/11 x64 и встроенный Windows PowerShell 5.1. EXE не устанавливает службу и не меняет системные настройки сам по себе; права администратора запрашиваются для запуска и остановки WinDivert/zapret.

## Возможности

- поиск стратегий `general*.bat`, выбор и просмотр краткой сводки параметров;
- запуск исходного BAT-файла без переписывания его аргументов;
- проверка и остановка `winws.exe`, запущенного именно из текущей папки;
- настройка Game Filter и диапазонов TCP/UDP-портов, режима IPSet и фоновой проверки обновлений;
- запуск оригинального `service.bat` для установки/удаления автозапуска, диагностики и тестирования.

Настройки сохраняются в файлы, которые уже использует сборка: `utils\game_filter.enabled`, `lists\ipset-all.txt` и `utils\check_updates.enabled`. Изменения Game Filter и IPSet применяются после перезапуска стратегии.

## Сборка EXE из исходников

Для пересборки нужны Python 3 и Zig 0.13+:

```text
python -m pip install ziglang==0.13.0
python app\build_exe.py
```

Скрипт собирает x64 Windows GUI-EXE и встраивает актуальный `ZapretManager.ps1`. Исходники лаунчера находятся в `app\launcher.c` и `app\build_exe.py`.

## Важно

- EXE не имеет цифровой подписи; Windows может показать предупреждение SmartScreen. Запускайте только файл из доверенной сборки и не отключайте антивирус ради запуска.
- Стратегии зависят от провайдера и могут не работать в конкретной сети. Для проверки и диагностики используйте `service.bat`.
- Кнопка остановки затрагивает только процессы `winws.exe`, путь которых совпадает с `bin\winws.exe` этой сборки. Процессы из других папок приложение не завершает.
- Режим IPSet «Любой IP» может повлиять на доступность сайтов и приложений вне списка; приложение просит подтвердить это изменение.
- WinDivert — системный драйвер; антивирус может сообщать о нём. Проверяйте происхождение файлов.
