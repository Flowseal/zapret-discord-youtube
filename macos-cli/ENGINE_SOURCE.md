# Происхождение движка

База: Flowseal/zapret-mac-discord-youtube, commit
`94c3b5125b4904ce2f6aec0e2197fe17f2fadf14`, каталог `nfq`.
Исходные уведомления об авторских правах и MIT-лицензия сохранены в `engine/`.

В этом экспериментальном CLI-варианте:

- utun unit и физический интерфейс/шлюз передаются через окружение;
- исходящие кадры отправляются через открытый BPF с Ethernet-заголовком;
- поддержаны отдельный жизненный цикл launchd, сброс привилегий и ранний отказ
  при ошибке BPF reinjection;
- Makefile собирает universal arm64/x86_64 для macOS 14+;
- инициализация UDP `desync_fwmark` перенесена до раннего `goto send_orig`.

Последняя ошибка воспроизводится `tests/udp-fwmark-harness.c`: при пропуске
desync interval передавалось неинициализированное значение mark. На macOS
этот mark не используется отправщиком, но само чтение было некорректным.

Копия движка включена явно, чтобы сборка не зависела от незакреплённой загрузки
стороннего исходного кода во время установки. Дальнейшую синхронизацию с macOS-форком
и необходимость такого размещения предлагается обсудить при review.
