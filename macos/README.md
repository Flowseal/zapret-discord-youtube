> [!WARNING]
>
> ### VPN
> Обход и VPN одновременно не работают — и не нужны: сквозь туннель провайдер видит только
> шифрованный канал. Пока поднят VPN, обход сам приостанавливается и возвращается, когда
> VPN выключают. Подбор стратегий и проверки запускайте **с выключенным VPN**.

> [!NOTE]
>
> ### Пароль администратора
> Перехват пакетов на macOS требует прав root (firewall `pf`, виртуальный интерфейс `utun`,
> `BPF`). Меню спрашивает пароль только для пунктов, которым он действительно нужен. Пароль
> никуда не сохраняется — его спрашивает системный `sudo`.

## ⚙️Использование

1. Включите Безопасный DNS (Secure DNS)
    * В Chrome — «Использовать безопасный DNS» и выбрать поставщика, отличного от «Поставщик по умолчанию»
    * В Firefox — «DNS через HTTPS», режим «Персональный», например `https://dns.google/dns-query`
    * Safari берёт DNS у системы: для него нужен профиль DNS-over-HTTPS от поставщика DNS (файл `.mobileconfig`, устанавливается двойным щелчком и подтверждается в Системных настройках)

2. Установите Command Line Tools. Это нужно один раз, и больше ничего устанавливать не надо (подробнее — [ниже](#что-нужно-установить)):
    ```sh
    xcode-select --install
    ```

3. Скачайте архив со [страницы последнего релиза](https://github.com/Flowseal/zapret-discord-youtube/releases/latest) и распакуйте по пути без кириллицы и спецсимволов

4. Снимите «карантин» с папки — это аналог галочки «Разблокировать» в Windows. Без этого macOS не даст открыть скрипты из скачанного архива:
    ```sh
    xattr -dr com.apple.quarantine путь/к/папке/zapret-discord-youtube
    ```
    Или: правый щелчок по `service.command` → «Открыть» → «Открыть»

5. Дважды щёлкните по **[`macos/service.command`](./service.command)** — в Терминале откроется меню. Дальше по порядку:
    * `12` — собрать движки (минута-две, нужен интернет)
    * `8` — проверить бэкенд (`selftest`)
    * `7` — **узнать рабочую стратегию**: перебираются все `general*.bat`, как `Run Tests` → `Standard tests` → `All configs` в Windows
    * `4` — **поставить на автозапуск** найденную стратегию

    После включения обхода **перезапустите браузер**: соединения, открытые до запуска, обход не затрагивает.

## Что нужно установить

**Только Command Line Tools** (`xcode-select --install`, около гигабайта; полный Xcode тоже подойдёт). Никаких языков программирования и менеджеров пакетов качать не нужно: ни Python, ни Homebrew, ни Go, ни Node.js.

| Что | Откуда | Зачем |
|---|---|---|
| `clang`, `make` | Command Line Tools | собрать из исходников на C движки `macws`, `tpws` и браузерную пробу `bigch` |
| `bash`, `curl`, `pfctl`, `launchctl`, `sudo` | встроены в macOS | меню, скрипт, проверки, firewall, автозапуск |
| Network.framework | встроен в macOS | браузерная проба — тот же TLS-стек, что у Safari |
| исходники zapret | GitHub, скачиваются при сборке | один раз, несколько мегабайт |

Интернет нужен только для сборки и обновления — сам обход работает без обращений к GitHub.

## ℹ️Краткие описания файлов

- [**`general*.bat`**](../) — стратегии. **Те же файлы, что в Windows**: macOS-версия сама читает из них параметры и порты, редактировать ничего не нужно. Пробуйте разные стратегии (ALT, FAKE и другие), пока не найдёте рабочую

- [**`macos/service.command`**](./service.command) — меню, аналог `service.bat`. Запускается двойным щелчком в Finder:
  - **`1. Включить обход`** / **`2. Остановить`** / **`3. Перезапустить`** — с выбранной стратегией
  - <ins>**`4. Установить в автозапуск`** — обход запускается вместе с системой (launchd) и сам поднимается, если упадёт</ins>
  - **`5. Убрать автозапуск`** — удалить службу и правила firewall
  - **`6. Выбрать стратегию`** — из списка `general*.bat`
  - **`7. Подобрать стратегию (тесты)`** — перебор всех стратегий на сайтах из [`utils/targets.txt`](../utils/targets.txt), в конце — рекомендованная ([как она выбирается](#как-выбирается-рекомендуемая-стратегия)). Если обход был включён, после теста он включается снова, уже с рекомендованной стратегией
  - **`8. Проверить бэкенд macws (selftest)`** — проверяет, что перехват и отправка пакетов работают на вашем Mac. Нужен один раз после сборки
  - **`9. Переключить движок`** — `macws` (полный, по умолчанию) / `tpws` (запасной, только TCP) / `auto`
  - **`10. Game Filter`** — обход для игр и других программ на портах выше 1023 (`off` / `tcp` / `udp` / `all`).
  **После переключения требуется перезапуск стратегии.**
  - **`11. IPSet Filter`** — режим обхода адресов из `ipset-all.txt`:
    - `none` — никакие адреса не попадают под проверку
    - `loaded` — адрес проверяется на вхождение в список (список при этом обновляется)
    - `any` — любой адрес попадает под фильтр
  - **`12. Собрать / обновить движки`**
  - **`13. Диагностика`** — что именно блокирует (DNS, адрес или DPI по имени) и состояние обхода
  - **`14. QUIC`** — `block` (по умолчанию: HTTP/3 глушится, и браузер уходит на TCP, который обходится) / `fake` (фейки QUIC по стратегии, как в Windows)

  В шапке меню видно, включён ли обход, какая стратегия и какие режимы выбраны.

- [**`macos/zapret.sh`**](./zapret.sh) — то же самое командами, для тех, кому удобнее терминал:

  ```sh
  ./macos/zapret.sh build                      # собрать
  sudo ./macos/zapret.sh selftest              # проверить бэкенд
  sudo ./macos/zapret.sh test-bat              # подобрать стратегию
  sudo ./macos/zapret.sh start "ALT11"         # включить (имя можно писать коротко)
  sudo ./macos/zapret.sh install "ALT11"       # автозапуск
  sudo ./macos/zapret.sh stop                  # выключить
       ./macos/zapret.sh status                # состояние
       ./macos/zapret.sh diag                  # что блокирует
  sudo ./macos/zapret.sh uninstall             # убрать всё
  ```
  Полный список — `./macos/zapret.sh help`

- [**`macos/config`**](./config.example) — настройки. Создаётся сам, когда вы что-то переключаете в меню; все параметры с пояснениями — в [`config.example`](./config.example)

- [**`macos/strategies.conf`**](./strategies.conf) — стратегии запасного движка `tpws`

- [`macos/src`](./src), [`macos/patches`](./patches) — исходники всего, что добавлено к zapret. Папки `macos/bin`, `macos/.build` и `macos/.state` создаются при сборке и работе и в git не попадают

### Чем отличается от Windows-версии

| Windows | macOS |
|---|---|
| `winws.exe` + драйвер WinDivert | `macws` — тот же движок, перехват через `pf` + `utun` + `BPF` |
| `service.bat` | `macos/service.command` |
| служба в `services.msc` | служба `launchd` (`/Library/LaunchDaemons/zapret.plist`) |
| `general*.bat` | **те же файлы** |
| `lists/*.txt` | **те же файлы** |
| `Run Tests` | `7. Подобрать стратегию` — дополнительно проверяет сайты «как браузер» |
| `Run Diagnostics` | `13. Диагностика` — проверяет, что именно блокирует |
| `Update IPSet List` | `11. IPSet Filter` → `loaded` или `./macos/zapret.sh update-ipset` |
| `Update Hosts File`, `Check for Updates`, `Auto-Update Check`, `Replace active fakes`, очистка кэша Discord | нет |

## 🔧Как это работает

В Windows пакеты перехватывает драйвер WinDivert. В macOS готового механизма для этого нет
(ни NFQUEUE, ни divert-сокетов, а в `pf` нет `divert-packet`), поэтому он собран из
штатных частей системы:

```
 браузер, Discord, игры
        │  обычные соединения
        ▼
 ядро macOS (TCP/IP) ── firewall pf: правило route-to для портов и адресов из .bat
        │
        ▼
 utun — виртуальный интерфейс (как у VPN), пакеты попадают в программу
        │
        ▼
 macws — логика winws без изменений: списки, fake, split, seqovl, QUIC, UDP
        │  изменённые пакеты
        ▼
 BPF — готовый кадр пишется прямо в Wi-Fi/Ethernet, мимо pf (петли нет)
        │
        ▼
 провайдер (DPI) → сервер
```

1. **Стратегии.** Скрипт читает `.bat`: из `--wf-tcp`/`--wf-udp` строит правила `pf`, а всё
   остальное (`%BIN%`, `%LISTS%`, `%GameFilter%`, профили `--new`) передаёт движку как есть.
   Поэтому стратегии из Windows-версии работают без правок, а новые появляются сразу.
2. **Перехват.** В `pf` добавляется отдельный раздел (anchor `zapret`) с правилами вида
   `pass out route-to (utunN …) proto tcp to port {80,443,…}`. Локальные сети исключаются
   по `lists/ipset-exclude.txt`. Остальные правила системы и VPN не трогаются.
3. **Обработка.** Движок — это `nfqws` из zapret (тот же, что внутри `winws.exe`); к нему
   добавлен только слой ввода-вывода для macOS. Логика обхода не изменена.
4. **Отправка.** Изменённые пакеты пишутся готовым кадром в сетевой интерфейс через `BPF`.
   Через `pf` повторно они не проходят, поэтому петли нет. Контрольные суммы, которые в
   Windows считает система, бэкенд считает сам.
5. **Входящие пакеты** идут штатным путём ядра. Движку показывается лишь копия ответов на
   установку соединения: по ним он вычисляет число хопов до провайдера (`autottl`).
6. **Крупные пакеты.** Сетевые карты Mac умеют TSO: ядро отдаёт большой запрос одним
   «суперпакетом», который не проходит через `utun`, и браузерный ClientHello приходит в
   движок по частям, задом наперёд. Поэтому на время работы обхода TSO выключается
   (`net.inet.tcp.tso=0`), а при остановке включается обратно.
7. **VPN и чужие правила.** Сторож раз в 10 секунд проверяет маршрут: пока трафик уходит в
   туннель, правила перехвата снимаются, потом возвращаются. Если клиент VPN перезагрузит
   firewall своим набором правил, сторож вернёт ссылку на раздел `zapret`, сохранив чужие
   правила.
8. **IPv6** обходится так же, как IPv4, если есть маршрут и `selftest` его подтвердил. Если
   нет — IPv6 на этих портах глушится с ответом, и программы сразу уходят на IPv4.
9. **Автозапуск** — служба `launchd` с перезапуском при падении. Лог — `/var/log/zapret.log`.
10. **Запасной движок `tpws`** — прозрачный прокси из zapret. Он работает без перехвата
    пакетов, поэтому умеет только TCP-стратегии (split/disorder/oob/tlsrec), без fake,
    seqovl, QUIC и UDP. Включается сам, если `selftest` не прошёл.

### Как выбирается рекомендуемая стратегия

Каждая стратегия проверяется на сайтах из `utils/targets.txt` двумя способами:

- **браузер** — настоящее TLS-рукопожатие системным стеком Apple, как у Safari. Запрос
  (ClientHello) весит 1538 байт и уходит **двумя** пакетами — так же, как у Chrome, Safari
  и Firefox (основной вес даёт постквантовый ключ);
- **curl** — маленький запрос в **одном** пакете.

DPI ведёт себя с ними по-разному, поэтому стратегия может открывать сайты в `curl` и не
открывать в браузере. **Главным считается браузер**, а `curl` решает при равенстве:
«браузер 8/8, curl 6/8» лучше, чем «браузер 7/8, curl 8/8». Стратегии, которые ломают
сайт, открывавшийся и без обхода, в рекомендацию не попадают:

```
   general (ALT11).bat                curl 8/8  браузер 8/8
   general (ALT6).bat                 curl 8/8  браузер 6/8
...
лучшая стратегия: general (ALT11).bat (браузер 8/8, curl 8/8, ничего не ломает)
```

## ☑️Распространенные вопросы и проблемы

### «Не удаётся открыть service.command: разработчик не подтверждён»

- Снимите карантин (шаг 4 в разделе [Использование](#%EF%B8%8Fиспользование)) или сделайте правый щелчок → «Открыть»

### `selftest` не проходит

- Выключите VPN и повторите
- Если не помогло, движком останется `tpws` (только TCP-стратегии). Подбор стратегии для него — тот же пункт `7`

### Тест пишет, что сайты открываются, а в браузере не грузится

- Перезапустите браузер после включения обхода — старые соединения обход не затрагивает
- Проверьте, что `14. QUIC` стоит в `block`, и снова перезапустите браузер (он запоминает, что сайт умеет HTTP/3)
- Смотрите в результатах теста на колонку «браузер», а не на `curl`
- Проверьте, не включён ли VPN

### Ни одна стратегия не подходит

- Запустите `13. Диагностика`. Она отвечает, лечится ли блокировка вообще:
  - «рвётся только с SNI» — блокировка по имени, её лечит стратегия
  - «TCP не устанавливается», «TLS не проходит и без SNI» — блокировка по адресу. Здесь не поможет никакая стратегия zapret, ни на macOS, ни на Windows: нужен VPN или прокси
  - «DNS не разрешается» — подмена DNS: включите Secure DNS
- Проверьте другие стратегии (**`ALT`**/**`FAKE`** и другие) и режимы `IPSet Filter`

> [!IMPORTANT]
> **Стратегии со временем могут переставать работать.** Если раньше работало, а перестало, снова запустите `7. Подобрать стратегию`.

### Сайты перестали открываться совсем

Обход заворачивает трафик на нужных портах в движок. Если движок аварийно остановился,
а правила остались, сайты не откроются. Выключите обход — это снимет правила и вернёт
настройки системы:

```sh
sudo ./macos/zapret.sh stop
```

Аварийно, если скрипт недоступен:

```sh
sudo pfctl -a zapret -F all
sudo sysctl -w net.inet.tcp.tso=1
```

### После включения VPN обход «пропал»

- Так и задумано: сквозь туннель обход не нужен. После выключения VPN он вернётся сам в течение 10 секунд

### Не работает игра/приложение с включённым запретом

- Проверьте, что `Game Filter` стоит в **`off`**, а `IPSet Filter` — в **`none`**. Иначе это может затронуть доступность ресурсов, которых вы не ожидали

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Поставьте `14. QUIC` в `block`, перезапустите обход и браузер
- Отключите блокировщик рекламы
- Пробуйте другие стратегии

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Желательно сначала найти стратегию, на которой открывается YouTube
- Проверьте Discord в браузере: https://discord.com/app. Если там работает, а в приложении нет — перезапустите приложение
- Голосовые каналы идут по UDP — их обходит только движок `macws` (не `tpws`)

### Как переустановить/обновить полностью?

```sh
sudo ./macos/zapret.sh uninstall      # убрать службу, правила и настройки системы
```

Затем скачайте новую версию и повторите шаги из раздела [Использование](#%EF%B8%8Fиспользование).
Чтобы обновить только движки: `12. Собрать / обновить движки`, затем `3. Перезапустить`.

- Создайте её [тут](https://github.com/Flowseal/zapret-discord-youtube/issues): укажите, что речь о macOS, и приложите вывод `./macos/zapret.sh status`

## 🐞Отладочные функции

Функции, которых нет в оригинальном `service.bat`, **по умолчанию выключены**, но не
удалены. Они нужны, чтобы разбираться с неполадками, а не для повседневной работы.
Включаются строкой в `macos/config`:

```sh
DEBUG_TOOLS=1
```

После этого в меню появляются пункты `15` и `16`, а в `./macos/zapret.sh help` — раздел «Отладка».
Включить разово, не меняя настройки: `sudo DEBUG_TOOLS=1 ./macos/zapret.sh <команда>`.

| Команда | Что делает |
|---|---|
| `debug [стратегия]` (пункт 15) | движок на переднем плане, подробный лог каждого пакета в `macos/.state/debug.log` |
| `why [сайт] [стратегия]` (пункт 16) | разбор одного сайта: пять проб разного вида без обхода и с обходом — блокируют по имени или по адресу, лечится ли это стратегией |
| `tune [сайт]` | перебор 46 наборов параметров обхода на одном сайте |
| `trace [стратегия] [адрес]` | разбор одного соединения по шагам |
| `logsum [файл]` | сводка по логу движка |
| `bigch [сайт]` | браузерная проба вручную; `bigch --selfcheck` измеряет размер запроса |
| `check [стратегия]` | показать правила pf и проверить параметры, ничего не применяя |

Кроме того, при `DEBUG_TOOLS=1`:

- тест стратегий пишет полный лог движка и отмечает стратегии, при которых движок ни разу не вмешался;
- движок проверяет, дошли ли его пакеты до сетевой карты («wire audit»), и пишет в лог состояние pf.

| `MACWS_UPLINK`, `MACWS_UPLINK6` | интерфейс выхода для IPv4/IPv6, если он определяется неверно |
| `MACWS_INJECT` | способ отправки: `auto` (по умолчанию), `bpf`, `raw` |
| `MACWS_TSO` | `keep` — не выключать TSO на время работы |
| `MACWS_INBOUND` | `0` — не показывать движку входящие пакеты (тогда не работает `autottl`) |
| `MACWS_DIAG`, `MACWS_WIRE_AUDIT` | расширенная диагностика движка (включаются через `DEBUG_TOOLS=1`) |
| `MACWS_UTUN_LOCAL`, `MACWS_UTUN_PEER`, `MACWS_UTUN_MTU` | параметры `utun` для IPv4 |
| `MACWS_UTUN_LOCAL6`, `MACWS_UTUN_PEER6` | адреса `utun` для IPv6 |
| `MACWS_MAX_PPS` | предохранитель от петли, по умолчанию 200000 пакетов/с |
| `MACWS_SELFTEST_DNS`, `MACWS_SELFTEST_DNS6` | резолверы, на которых `selftest` проверяет отправку |

</details>

## 🗒️Добавление адресов прочих ресурсов

Списки общие с Windows-версией и лежат в папке [`lists`](../lists):
- **`list-general-user.txt`** для доменов (поддомены автоматически учитываются)
- **`list-exclude-user.txt`** для исключения доменов
- **`ipset-all.txt`** для IP и подсетей
- **`ipset-exclude-user.txt`** для исключения IP и подсетей

После изменения списков выберите `3. Перезапустить`.
