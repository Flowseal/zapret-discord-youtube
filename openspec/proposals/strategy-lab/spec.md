# Proposal: конструктор стратегий

## Цель

Вкладка для сборки argv `winws` без правки `.bat` вручную: все известные флаги, профили `--new`, быстрый HTTPS-smoke, сохранение `general (DEV …).bat`.

## Поведение

- Вкладки «Стратегии» и «Конструктор»; `winws` по-прежнему не через `.bat`
- Черновик: глобальные `--wf-*` + профили; каталог опций + merge `winws --help`
- Числа — слайдеры; повторяемые флаги — список значений
- Быстрый тест: тот же Discord/YouTube smoke, без службы
- Сохранение в корень пака; загрузка выбранной стратегии; стоковые `.bat` не перезаписывать без подтверждения

## Риски и побочные эффекты

- Невалидный argv роняет `winws`; тест рвёт текущее подключение
- Запись `.bat` в каталог пака
