# Proposal: лёгкий WPF UI (MVP)

## Цель

Пользователь запускает один `.exe` от администратора, проверяет стратегии, подключает выбранную, при желании ставит автозапуск.

## Поведение

- Список всех `*.bat` кроме `service*`
- Подключить / отключить: скрытый `winws.exe` или служба `zapret`
- Проверить все: последовательный HTTPS-smoke (Discord + YouTube из `utils/targets.txt`)
- Автозапуск: `sc create zapret` / remove как в `service.bat`
- Трей, опрос статуса не чаще 2 с
- Предупреждение о кириллице и OneDrive в пути

## Риски и побочные эффекты

- Требует UAC; WinDivert может триггерить антивирус (как у исходного пака)
- HTTPS-smoke не гарантирует голосовой Discord
- Одновременно может работать только один `winws`
- Self-contained WPF занимает десятки МБ на диске из‑за рантайма .NET
