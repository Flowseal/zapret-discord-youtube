# Spec: WPF UI

## Требования

- Один процесс обхода: либо `winws.exe`, либо служба `zapret`
- Не запускать `.bat` напрямую
- Перед стартом создавать user-lists и подставлять Game Filter из `utils/game_filter.enabled`
- Тест всех стратегий отменяемый, без правки `ipset-all.txt`
- Вкладка «Конструктор»: argv `winws` без прямого запуска `.bat` (см. `strategy-lab`)

## Риски и побочные эффекты

- Конфликт с уже установленной службой `zapret` / другими обходами
- Путь в OneDrive ломает WinDivert у части пользователей
