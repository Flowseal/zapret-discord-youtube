# Spec: конструктор стратегий

## Требования

- Вкладка «Конструктор» рядом со списком стратегий
- Не запускать `.bat` напрямую: argv собирается в UI и передаётся в `winws.exe`
- Каталог флагов winws (зашитый + неизвестные из `--help` как строки)
- Профили разделяются `--new`; глобальные WinDivert-фильтры отдельно
- Числовые параметры — слайдер + поле; повторяемые параметры — добавление/удаление значений
- Быстрый тест: HTTPS-smoke Discord+YouTube, без службы `zapret`, с остановкой текущего `winws`
- Сохранение `general (DEV {имя}).bat` в корне пака в формате Flowseal (`%BIN%`, `%LISTS%`, `%GameFilter*%`)
- Загрузка выбранной стратегии в черновик; стоковые файлы — только с подтверждением перезаписи

## Риски и побочные эффекты

- Произвольный argv может сломать обход или сеть до отключения
- Тест и подключение черновика останавливают текущий процесс обхода
- Сохранение в каталог пака (OneDrive/кириллица в пути — как у остального UI)
